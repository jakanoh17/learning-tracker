# learning-tracker

A single page React app for tracking what I'm learning each week.

## Commands

Run these from the workspace root:

```sh
pnpm nx dev learning-tracker     # Start the dev server on http://localhost:4200
pnpm nx test learning-tracker    # Run unit tests (Vitest)
pnpm nx lint learning-tracker    # Lint
pnpm nx build learning-tracker   # Production build into packages/app/dist
```
