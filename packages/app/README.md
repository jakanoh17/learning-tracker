# learning-tracker

A single page React app for tracking what I'm learning each week.

## Commands

Run these from the workspace root:

```sh
npx nx dev learning-tracker     # Start the dev server on http://localhost:4200
npx nx test learning-tracker    # Run unit tests (Vitest)
npx nx lint learning-tracker    # Lint
npx nx build learning-tracker   # Production build into packages/app/dist
```
